<details>
<summary><b>💧 Smart Water Tank — Fuzzy Sugeno</b></summary>Description

An IoT-based smart water tank system using Fuzzy Sugeno for adaptive control of the distribution pump.

Control Architecture

Water Level ────────┐
                    ├──> Fuzzy Sugeno ──> Pump Duration
Water Flow ─────────┘

Technology

Attribute| Implementation
Controller| ESP32
Method| Fuzzy Sugeno
Inputs| Water Level + Flow Rate
Output| Pump Operating Duration
Connectivity| IoT
Evaluation| Fuzzy vs ON/OFF

Research Objective

To evaluate whether adaptive fuzzy control can improve pump operation compared with conventional ON/OFF control in terms of:

- Operating time
- Control responsiveness
- Water distribution
- Estimated energy consumption
